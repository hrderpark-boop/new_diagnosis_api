## P0-1 ALIGN 결정론 조립 — `services/align_render.py`
- 구조: [LLM 공감 되받기 2~3문장] + [고정 정의 1문장] + [목록 `· ` 줄 전부] + [고정 안내 "이 N가지를 하나씩…"] + [고정 다리 "먼저 ~쪽부터요."] + [앵커 1개].
  5개 챕터(3~9개) 모두 같은 렌더러. 고정 문장은 전부 `PERSONA_LINES`(6명 변형).
- LLM 출력에서 제거: 질문·간접 질문(여쭙니다·들려주세요 류)·목록 줄·하위역량 나열 문장·다른 챕터 이름이 든 문장·
  선택을 넘기는 문장('어느 쪽부터', '자주 쓰시는 쪽부터')·리더 답변 복사 문장.
- layer3 ALIGN 지시는 "되받기 평서문만" 으로 축소. 정의·목록·'조직을 효과적으로…' 예시는 프롬프트에서 뺐다(일관리 ALIGN 유입 원인).
- **조립 뒤 재생성 금지**: 8-i(출력 가드)·8-n(입버릇 가드)이 ALIGN 을 재생성하면 LLM 새 출력이 조립 결과를 덮는다 — 재생 1·2라운드에서
  챕터 2~4 ALIGN 목록 누락의 실제 원인. 되받기의 누설 처리는 조립 '전'에 한다.
- ALIGN 직후 '네/넵/네?/??/sp' → `ANCHOR_REASK`("그럼 여쭤볼게요. [앵커]"). "짧게 답하셨네요" 류 문구 없음.
